# Terminology Guidance

This guide includes Kenya-specific terminology to support emergency and
ambulance workflows.

## Core Emergency Terminology

The IG defines CodeSystems and ValueSets for:

- case priority
- ambulance case status
- ambulance case rejection reason
- pulse state classification
- breathing state classification
- condition status
- allergy reporter
- coding system source
- medication administration route
- dose units
- questionnaire category
- entry types
- assessment types

## Investigation Codes

Diagnostic reporting in the emergency workflow uses an investigations value set
that supports laboratory and imaging-oriented coding needed for urgent care and
handover scenarios.

## Terminology Source Pattern

The terminology content in this IG is modeled as local implementation-guide
artifacts while remaining aligned to Kenya emergency workflow concepts and
terminology governance patterns used across the broader ecosystem.
